# 露营攻略网站

一个包含**前端内容网站**与**后台管理系统**的 Node.js 项目：
- 前端按中国市级整理露营地点。
- 每个露营地点有主图、物品清单、注意事项。
- 后台支持新增、编辑、删除攻略。

## 启动方式

```bash
node server.js
```

访问：
- 前台首页：`http://localhost:3000/`
- 后台管理：`http://localhost:3000/admin`

## 功能说明

### 前台网站
- 城市聚合展示露营攻略。
- 城市详情页查看该市全部露营地点。
- 露营攻略详情页展示：主图、清单、注意事项。

### 后台管理网站
- 攻略列表查看。
- 新增攻略（可录入城市、地点、主图 URL、清单、注意事项）。
- 编辑与删除已有攻略。

## 数据存储
- 使用 `data/campgrounds.json` 做轻量级内容存储。
- 适合原型和内容型网站快速搭建。
